# Duet AI Native 视频脚本

**从个人委托到业务闭环**

每个分镜的列表按顺序配音，并作为中文字幕。画面说明供剪辑使用。

## 01 一次个人委托

画面跟随一条消息，从鲍勃的真人私聊进入 My Duet，再回到原私聊。

- 鲍勃发来一条消息，请我做一份报表。
- 我引用他的消息，对自己的 Duet 说，帮我做好报表，然后发给鲍勃。
- Duet 完成报表，按这次任务的明确委托，替我把它发到原来的私聊。
- 鲍勃收到报表，继续手上的工作。一次个人委托，就这样接上了别人的下一步。
- 当这种交接一段段连起来，公司的部分业务就可以自己运转。

## 02 一个持续的 Duet

由单一入口展开到滚动上下文、Dream 和 Tracking。

- 每位员工都有一个自己的 Duet，可以教它自己的职责、偏好和做事方式。
- 你每天面对同一个 Duet。最近几条问答保留原文，较早的对话持续压缩成摘要。
- 每四小时，Dream 从主人可见的群聊和自己与 Duet 的对话中，增量整理长期记忆。
- Git 保留记忆的版本和差异，条目关联来源。以后改了决定，也能回查缘由。
- 要跨天推进的事，Duet 创建一条 Tracking。首节点帮助找回事项，后续进度接着写入。

## 03 从真人群聊到 Agent 主题

真人群聊和关联主题并列。消息的快捷操作只连接同一员工的 Duet，主题内才显示 Agent 之间的协作。

- 群聊里始终是真人在对话。看到一条消息，你可以把它交给自己的 Duet 处理。
- 只有自己的 Duet 接收这次快捷操作。它可以带着消息去完成任务。
- 如果群聊绑定了主题，Duet 可以去主题留言。发起主题的 Duet 负责管理。
- Duet 在主题里邀请其他 Duet 异步接手。相关的文件和历史按群聊权限共享。

## 04 代码审查如何接力

PR 创建后沿规则进入评审，修改意见写回 PR，原作者的 Duet 提交修复。

- 一次代码改动提交后，GitHub 发出 PR 创建事件。
- Agent Loop 读取规则，把它交给评审负责人的 Duet。外圈按确定的规则运行，无需模型。
- 评审 Duet 检查改动，返回结论。需要修改时，规则可以把意见写回 PR。
- 原作者的 Duet 收到事件，修复问题并追加提交。新版本可以进入复审或验收。

## 05 用证据完成验收

从测试编排切换到独立浏览器，显示页面断言、截图和可回流的测试结果。

- 需要验收时，LoopLab 把需求和用例编排成可复用的测试。
- 独立浏览器回放固定版本的流程，留下页面断言、执行步骤和截图。
- 结果可以作为可读报告进入 Message Center，也能成为 Agent Loop 的下一条触发事件。
- 失败就把证据交回负责修复的 Duet。通过后，按规则继续，或由负责人作决定。

## 06 一条资讯如何推动项目

公开资讯进入 Message Center，市场 Duet 识别相关性，员工决定是否调研和组织协作。

- 有些工作从一条资讯开始。爬虫发现银行业监管政策变化，把原文和摘要放进消息中心。
- 市场同事的 Duet 定期查阅资讯，发现这条变化可能影响主人正在跟进的项目。
- 市场同事判断值得跟进，就让 Duet 补充调研，整理报告，并把建议写成需求。
- 团队可以建立真人群和对应主题，由相关 Duet 各自接手，把工作推进到验收。

## 07 从个人委托到业务闭环

镜头拉远，出现外圈 Agent Loop 和圆内的 Duet、Message Center、LoopLab。保留员工做决定的位置。

- 团队先把真实工作做顺，再把反复发生的交接写进规则。
- Agent Loop 调度，Message Center 汇集信息，Duet 执行，LoopLab 提供验收证据。
- 人依然决定做什么、何时承诺，以及怎样判断完成。每个人交出一小段工作，就能接起一条业务闭环。
