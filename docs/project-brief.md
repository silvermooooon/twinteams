# Duet project brief

Duet is a React frontend and Python 3.13 FastAPI application backed by PostgreSQL, Redis and the separate Agent Runtime SDK. Human conversations, owner-private assistance and approved Duet communication are separate experiences.

The current product and implementation are specified in [product requirements](product-requirements.md), [interaction rules](interaction-rules.md), [architecture](architecture.md) and [implementation contract](implementation-contract.md). The approved visual identity is documented in [visual identity](visual-identity.md). Retired scaffold plans and mixed human/agent routing designs are not implementation guidance.
